Before Module 01

Four ideas every single module in this course leans on without re-explaining. Read them once, here, thoroughly. From Module 01 onward, tutorials will drop a small tag like [memory-model] linking back to the exact section they need — they will not re-teach it.

Why a prerequisites layer at all

A cooking course that says "dice the onion" in every recipe wastes your time twelve different ways. Teach knife skills once, well, up front — then every recipe after that can just say "dice the onion" and mean it. These four pages are the knife skills. Everything from Module 01 on is a recipe.

How to use this page

You don't need to memorize these four pages. You need to have seen them once, so that when a module tutorial says "as established in [memory-model], the array's elements are laid out contiguously," you know exactly where that claim was earned and can go re-read it if it's fuzzy.

Where to start

Read all four in order — each is short. Then move on to Module 01 — Memory & Addresses, where the course stops talking in the abstract and starts building real, running code.
